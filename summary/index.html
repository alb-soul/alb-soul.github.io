Temuan Kerentanan

RCE via File UploadUpload file tidak tervalidasi → eksekusi kode jarak jauh. Mitigasi: whitelist MIME, rename file, simpan di luar webroot, disable execute.
Cross-Site Scripting (XSS)Reflected / Stored. Mitigasi: output encoding, CSP, validasi input.
Sensitive Key ExposureAPI key / secret terekspos di client-side / repo. Mitigasi: env vars, rotate key, git history clean.
Client-Side Prototype PollutionPollusi objek JS via parameter. Mitigasi: sanitasi key __proto__/constructor/prototype, pakai library aman.
PII ExposureData pribadi terekspos di response/API. Mitigasi: minimasi data, authz check, masking.

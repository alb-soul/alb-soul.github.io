Pengalaman Keamanan Web

klik untuk buka/tutup • fokus pada perbaikan, tanpa detail sensitif
  • RCE via File Upload
    Mitigasi: whitelist MIME, rename file, simpan di luar webroot, disable execute.
  • XSS (Reflected / Stored)
    Mitigasi: output encoding, CSP, validasi input.
  • Sensitive Key Exposure
    Mitigasi: env vars, rotate key, bersihkan git history.
  • Client-Side Prototype Pollution
    Mitigasi: sanitasi key __proto__/constructor/prototype.
  • PII Exposure
    Mitigasi: minimasi data, authz check, masking.
